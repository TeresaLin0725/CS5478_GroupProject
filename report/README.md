## 3. 跨实验一致的结论

1. **信息驱动的方法（IG、LLM）稳定优于 Nearest 和 Random。** 4 批实验结论一致：所有批次里 IG 和 LLM 的计罚时间都低于 Nearest 与 Random（中期基线中 IG 只领先约 12 s，其余批次差距明显）。语义实验中这一差异在配对符号检验下显著（p ≤ 0.002）；碗实验中 Random 对 LLM 的时间差区间为 [26, 118] s，全为正。

2. **LLM 相对 IG 没有稳定的整体优势，优势取决于目标在哪里。** 4 批实验呈现同一模式：
   - 厨房杯子（中期与鲁棒性基线）：LLM 计罚时间低于 IG（中期 193.4 对 266.4；鲁棒性无噪声 148.8 对 177.5，有噪声 127.8 对 183.1）；
   - 碗实验：厨房碗 LLM 更快（97.0 对 129.9），卫生间碗 IG 更快（73.3 对 111.0）；
   - 语义实验：语义合理摆放 LLM 更快（找到时间 106 对 143），反常摆放两者持平（148 对 153）。

   **合理的总结是：当目标在常识上的典型位置（尤其是厨房）时，LLM 往往更快；换成卫生间或反常位置，优势消失甚至反转。** 但每一批内部的 LLM 对 IG 差异都未达统计显著，这是跨实验观察到的一致趋势，不是已证实的效应。

3. **LLM 的路线通常更短。** 成功回合平均路径：鲁棒性基线 7.30 对 IG 13.12 m（无噪声），碗实验 8.24 对 9.44 m，语义实验 11.7 对 13.7 m。LLM 倾向于少走回头路，即使时间上不一定更快。

4. **LLM 的选择有相当一部分与几何启发式重合，"语义推理"的实际作用有限。** 语义实验中 44–52% 的 LLM 决策正好是每米信息增益最高的前沿；改进提示词让模型输出区域概率后，概率几乎不随目标类别变化（看到冰箱后对厨房的概率：杯子 0.39，剪刀 0.36）。碗报告也独立指出，LLM 直接走向卫生间时给出的理由主要是信息增益与路径代价，不能证明它推断出了碗在卫生间。

5. **更细的提示词工程收益很小。** 语义实验中，结构化的 v2 提示词对原始 v1 为 10 胜 15 平 6 负（p = 0.45），每次调用延迟从约 7–10 s 增加到 11–24 s。

6. **瓶颈正在从"去哪里找"转向"找到以后能否确认"。** 语义实验的 58 个浴室/书桌失败回合中，54 个已经把真实目标跟踪到 0.5 m 以内，失败发生在两帧近距离复核；11 次误报全部是场景里的其他瓶子被当成目标，与搜索策略无关。碗实验启用了鲁棒性配置（深度滤波核 5、未访问视点恢复、观察朝向稳定比例 0.5），卫生间碗 4 种方法共 22/24 成功。语义实验没有启用该配置，浴室目标全部失败。**下一步最值得做的是在语义实验的浴室任务上启用这套配置重新验证**，而不是继续调整高层策略。

## 4. 不能直接合并的地方

- **LLM 模型不同**：实验 1–3 用 Gemini 系列（碗实验为 gemini-3.5-flash-lite），实验 4 用 DeepSeek-V4.1-Flash。Gemini 免费额度为每天 20 次请求，无法支撑实验 4 的调用量（每回合最多 25 次）。
- **噪声与配置不同**：实验 2 有无噪声和有噪声两组，实验 3 有噪声，实验 4 无噪声；实验 3 使用碗专用的鲁棒性清单和 `bowl48_accessible` 家具布局，实验 4 使用 `legacy_cup` 清单。
- **任务与起点不同**：目标物体、位置和起点各不相同，因此各批的成功率和时间不能放在一起算总平均。本页只比较各批内部的方法排序是否一致。
- **样本量**：每个（起点，任务，方法）组合都只跑 1 次，仿真确定，变化只来自起点、场景条件和 LLM 自身的随机性。

## 5. 建议的报告写法

- **主结论**：信息驱动的前沿选择（IG / LLM）显著优于最近前沿与随机，这一点在 4 批实验中稳定成立。
- **LLM 的价值**：表述为"在目标位于语义典型位置时，LLM 倾向于更快、路线更短；在非典型位置无优势"，并注明未达统计显著。不要写成"LLM 优于信息增益"。
- **局限与下一步**：LLM 的决策大量复现几何启发式，提示词优化收益有限；系统瓶颈已转移到末端复核和感知误报。
