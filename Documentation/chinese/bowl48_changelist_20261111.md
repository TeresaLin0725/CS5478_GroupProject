# 碗搜索实验与报告变更清单

提交分支为 `integration/w2`。本次加入厨房与卫生间碗目标、两个起点的48轮有噪声基准，并提交已完成实验的中文报告和可移植证据存档。

## 实现

- 统一目标模型、类别、坐标与独立验收配置，支持 `kitchen_bowl` 和 `bathroom_bowl`。
- 增加 `bowl48` 冻结设计：两处目标、两个起点、三种条件、四种方法；固定实际噪声种子140，先厨房后卫生间，最多两轮并发。
- 为12组任务分别进行隔离物理预检查。`bowl48_accessible` 布局移开卫生间通道旁的新增椅子，同时用于两处目标与全部方法。
- 增加摆放与启动观察检查、实时报告、逐轮实际轨迹导出、原生渲染新增物体图层和场景轨迹图。
- 增加中文报告生成与仓库存档脚本。报告包含时间、路径、成功率、配对区间、失败案例及全部48轮明细。

## 实验结果

48轮全部完成，45轮成功，均无碰撞。Random成功11/12，Nearest成功10/12，IG和LLM均成功12/12。LLM在厨房任务中平均时间与路径更优，IG在卫生间任务中更优；整体IG与LLM效率差异的配对区间跨零。失败按既定规则保留，没有重跑替换。
