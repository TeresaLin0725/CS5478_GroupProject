# 当前 demo 的设计落实核对（2026-10-18）

核对入口：[当前 demo](../../report/index.html)。依据为英文 [详细实施计划](../english/robotics_project_detailed_plan.md) 和 [冻结接口](../english/interface_freeze.md)，再交叉检查实际源代码、测试、manifest、事件日志和独立验收证据。

结论：核心搜索闭环与当前 Rs 三条件的 36 回合、9 组四策略配对统计已完成验收。跨房屋泛化、目标位置多样性及全部 W4 原生可靠性用例仍未覆盖。下面区分实现、测试和原生运行证据。

当前 demo 采用已文档化的 1.1 扩展：除初始计划中的视觉发现，还要求接近与停稳确认；初始化启用半径 0.65 米内经实体碰撞列和地面支撑验证、且与足迹连通的自由栅格子集。它比 1.0 默认的“仅初始足迹自由”先验更强，不能当作严格足迹先验的结果。该子集只在初始化提供一次，不计作已观测覆盖；后续不再扩张，未知空间仍不可通行。见 [先验说明](../english/verified_start_area.md)。

物理运行也有明确配置边界：原有 Locobot 球形脚轮仅与平地碰撞，关闭了脚轮与扫描三角网格的碰撞以避免毫米级门槛卡住；驱动轮和车身保留扫描碰撞。日志中的接触数采用适配器的高度、力阈值与非地面接触口径，不是所有 Bullet 接触对的数量。推车为经过扫掠复检的脚本运动。这些设定应随正式实验 manifest 一起冻结。

## 当前控制与目标确认设计

控制器按 0.1 米栅格路径跟踪。原生集成入口的距离增益为 2/s，最大线速度 0.32 m/s，最大角速度 1.1 rad/s，并输出 `controller.json`；默认通用导航器仍使用原增益。规划方式、机器人几何、安全裕量、目标检测阈值及独立验收规则按原设计执行。

RGB-D 观测带有可选的控制步里程计：由适配器连续两次已知机器人位姿在 30 Hz 下计算线速度及角速度幅值，感知同时检查相机间隔差分和这份更高频的运动估计。它不包含物体坐标、实例 ID、场景占据或验收结果。感知侧角速度筛选为 0.02 rad/s，独立验收门槛为 0.10 rad/s；停止指令不会把上一控制步的运动量伪写为零。到达偏航容差 0.10 rad、扫描朝向容差 0.05 rad、扫描驻留 0.6 秒，四策略共用同一套配置。

停车多视角确认：仅在导航到达已观测目标的接近位置后，B 按相对目标朝向 `−0.15 / 0 / +0.15 rad` 的三个固定小角度观察，每个朝向制动驻留 4 秒，并继续真实物理步进、原间隔 RGB-D 采集及正常目标判断。每段转向先做完整足迹扫掠检查；形成声明立即交给独立评估器，未声明则继续原扫描与恢复。全局时间、步数、操作超时和取消预算持续生效。固定小角度的原因是：数度朝向差异即可令同一个杯子的检测从无结果变为约 0.78，单一视角延长停驻不能保证确认。

`ObservationConfig.inspection_hold_s` 默认 0（不开启），原生集成入口设为 4；`inspection_headings_rad` 记录固定小角度，`start_observation` 的可选 `inspection` 流程负责执行。四策略共用该行为，报告单列为“停车多视角确认目标”。公共 `WorldState` 和策略候选输入保持原结构。可选字段及所有权记录在 [1.1 扩展说明](../english/close_object_search.md)。回归覆盖“图像位姿看似相同但控制步发生转动”、停止指令与真实运动的区别、绕墙到达与零接触；合成用例不能代替原生物理试跑，因此录制前另做原生验证。

## 画面和展示改动

- 首屏以任务与实际运行指标为中心，主录像优先，完整配置折叠展示。
- 深色页面、统一颜色、阶段跳转、操作时间带、实时操作与决策说明、2× 默认演示 / 1× 原速核对、专注演示模式。
- 录像重新安排实体视图、观测地图与机器人相机，加入地图图例和清晰的仿真时间、距离、接触数。
- Locobot 部分非纹理网格的漫反射材质为纯黑；仅在第三人称展示渲染时临时使用石板灰材质及补光，并在 `finally` 中恢复。机器人传感器与私有验收渲染继续使用原始材质和灯光。
- 推车瓶子使用已安装的 YCB `006_mustard_bottle` 真实纹理网格，归一到原推车检查包络内，所有解析碰撞部件保持一致；避免简化圆柱瓶子被 YOLO 误判为杯子。阈值、检测模型、目标位置和独立验收条件没有放宽。
- H.264 编码质量从 CRF 22 改为 18；采集仍为真实物理步对应的 15 fps，不以插值轨迹或生成画面替代实体运动。

所有播放倍速都保留原始仿真时钟。
